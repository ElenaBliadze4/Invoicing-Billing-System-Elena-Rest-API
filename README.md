# Invoicing Billing System Elena REST API

###
წინამდებარე დავალებაში მინი პროექტში  ნავარჯიშებია Rest API ის შექმნა (მოცემული დავალება გითისთვის არის ასატვირთი დროებით დაუსრულებელია)


## პროექტის მიზანი
ინვოიცესების,მომხმარებლების მონაცემებისა , მათი გადახდის მართვის სისტემის აწყობა.

## გამოყენებული ტექნოლოგიები
- Java 25
- Spring Boot 4.0.6
- Spring Data JPA / Hibernate
- Mysql
- Git 
- Github

## გაშვების წესი

შეგვიძლია გავუშვათ მოცემულ ბმულზე : http://localhost:8080/swagger-ui/index.html#/

## Git Worklflow
1. გვაქვს ძირითადი დეველოპმენტ ტოტი: `develop`
2. ფუნქციონალებისთვის შევქმენით  `feature/user-profile` ტოტი.
3. Pull Request -ით გადადის ცვლილებები `develop` ტოტში.

## ნაბიჯების შესრულება
1. გავაკეთე ინიციალიზაცია და .gitignore დავამატე (რიდმი ფაილი თავიდანვე მქონდა და განახლებული დავამატე დავალების შესრულების შემდეგ)
2. შექმნილია  `develop` და `feature` ტოტები
3. `InvoiceItem` და `Payment` კლასებია დამატებული 
4. განვახორციელე 3 შინაარსობრივი კომიტი
